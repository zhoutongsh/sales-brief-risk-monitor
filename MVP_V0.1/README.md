# 日常销售数据动态监控 MVP V0.1

这是一个可以在本机直接运行的销售经营监控演示系统：每天从 CSV 源数据计算经营指标，自动识别 6 类销售风险，生成今日简报和周报，并支持风险认领、转派、关闭的完整闭环。

> **验收结论：** Gate C 通过（MVP 演示/试点范围，不等于生产验收）。详见 `docs/验收报告.md` 和 `docs/验收报告_简版.md`。

> **演示环境声明**
>
> 本系统仅用于本地演示和方案验证，**不是生产系统**。
> 登录是“选择演示账号”的一键登录，**不是生产认证**，没有密码、短信、单点登录。
> 请勿录入真实客户信息，请勿直接部署到公网。

## 一、5 分钟跑起来

### 方式 A：双击启动（推荐）

双击 `start.bat`。第一次启动会自动完成：

1. 建立 SQLite 数据库；
2. 生成 30 天演示 CSV 源数据；
3. 跑一次完整批处理；
4. 启动本地服务。

看到下面两行后，用浏览器打开：

- 系统页面：<http://127.0.0.1:8000>
- 接口文档：<http://127.0.0.1:8000/docs>

停止服务：在启动窗口按 `Ctrl+C`。

### 方式 B：命令行启动

在本目录打开终端：

```bat
.venv\Scripts\python scripts\init_demo.py
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

如果数据库已经存在，只需第二条命令。想恢复干净演示数据时，先关服务，再双击 `重置演示数据.bat`（或重新运行 `init_demo.py`，会删除并重建演示库）。

## 二、建议演示路径

1. 用 `u_gm` 登录，查看“今日简报”：3 条结论、6 张指标卡、风险 Top3、渠道表现、数据说明。
2. 进入“风险中心”，按级别/状态筛选，点开一条红色风险，查看证据链、SLA、关联对象和时间线。
3. 认领风险，填写处理计划；再关闭风险，填写原因、动作和结果。列表和统计会立即刷新。
4. 打开“周报复盘”，切换本周/上周，查看 6 张指标、三条结论、团队排名、每日签约节奏。
5. 在“导出中心”导出日报/风险 Excel，或打开打印版日报。导出前有二次确认，文件带“演示数据·禁止外传”水印。
6. 退出后用 `u_sm` 登录，风险数量会变少，且只能看到本部门数据；尝试转派会收到 403 提示。
7. 用 `u_gm` 打开“审计日志”，查看登录、查看、导出、认领、转派、关闭、改规则等动作。

## 三、已实现范围

### P0（本次交付）

- 演示登录、HMAC 签名 Cookie（HttpOnly、SameSite=Lax、8 小时有效）。
- 4 角色行级权限，列表/详情/导出/下钻全部在服务端过滤，越权返回 403。
- 手机号、邮箱在 API、页面、Excel 中统一脱敏。
- 10 个演示 CSV，30 天数据，自然触发 6 类风险；`data/expected_risks.csv` 是独立期望清单。
- 批处理链：抽取校验 → 12 项指标快照 → 数据质量 → 风险识别 → 日报 → 周报 → 发布 → 站内通知 → 超时升级检查。
- 同日重复跑批幂等：指标 UPSERT、风险复用、通知去重、日报更新、周报删重插；运行记录写入 `batch_runs`。
- 缺源文件时批次标记 `failed`，错误写明缺失文件名、路径和受影响指标；页面顶部横幅展示同一信息，业务事务回滚且不生成新的日报、周报或风险结论。
- 6 条风险规则：证据链、红/橙/黄分级、SLA、24 小时内同对象同规则合并、超时自动升级、状态机。
- 规划第六节 API 全部可用，OpenAPI 文档 `/docs`。
- 前端复用原型视觉，所有业务数据来自 API，没有本地假数据回退；接口失败显示错误，登录失效回登录页。
- 今日简报、风险中心、风险详情抽屉、周报、指标中心、数据质量、预警规则、消息中心、导出中心、打印日报、审计日志。
- 风险认领/转派/关闭真实闭环，所有关键动作写审计。

### P1（本次已做）

- 指标下钻、渠道分析、站内通知中心、打印版日报（水印、二次确认）。
- 规则启停/调参，仅总经理可操作。
- 20 个以上端到端自测场景（实际 32 个，含超时升级、发布时间、周报范围、四舍五入和缺源文件回滚）。

### 明确不做

- **不做手机端**：没有 `/m` 路由、H5 页面、手机预览和移动端适配。PC Web 在 1280–1600px 宽度下不横向溢出。
- 不做生产级账号体系、权限后台、审批流、邮件/短信、真实 CRM/ERP 对接。

## 四、数据与口径

- 演示业务日期：**2026-10-24（周六）**；数据范围 2026-09-25 至 2026-10-24，共 30 天。
- 源数据：`data/source/` 下 10 个 CSV；`data/expected_risks.csv` 列出预期 10 条风险。
- 金额：数据库以“元”存储，API 和页面以“万元”展示并保留 1 位小数。
- 比率：保留 1 位小数；缺失值返回 `null`，页面显示“—”，不用 0 代替。
- 批处理的业务日期固定，但“批次运行时间”取当前北京时间（+08:00），便于演示同一天重跑。
- 营销 ROI 的投放费用使用公司级 `ad_spend.csv`（源数据没有组织字段），因此 ROI 只做到公司级，页面数据说明中已标注。
- 线索异常、商机覆盖两类风险的“涉及金额”按期望清单为 0，页面显示 0；这不代表缺失值。

### 把演示数据换成真实数据

1. 按 `data/source/` 现有 CSV 的列名准备真实导出文件；
2. 或在 `app/ingest.py` 中调整字段映射；
3. 不需要改前端和 API，重新跑批即可。

## 五、批处理与风险规则

### 批处理顺序

`抽取校验 → 指标快照 → 数据质量 → 风险识别 → 日报 → 周报 → 发布 → 站内通知 → 超时升级检查`

日报放在风险之后，是因为今日简报的“风险 Top3”依赖风险结果；通知放在发布之后，避免通知到未发布的报告。

手工重跑：

```bat
.venv\Scripts\python scripts\run_daily.py
.venv\Scripts\python scripts\run_daily.py --date 2026-10-24
```

### 6 条风险规则

| 规则 | 触发条件（默认参数） | 级别 |
|---|---|---|
| 目标缺口 | 时间进度 − 目标完成率 ≥ 3 / 8 / 15 个百分点 | 黄 / 橙 / 红 |
| 业绩下滑 | 最近 3 个有数据工作日连续两段环比下降，降幅 ≥ 20% / 30% | 橙 / 红 |
| 线索异常 | 本周新增线索周环比 ≤ −30%，或转化率相对下降 ≥ 20% | 橙 / 黄 |
| 商机覆盖 | 开放商机管道 ÷ 剩余目标 < 2.5 倍 | 橙 |
| 大客户流失 | 开放商机金额 ≥ 50 万元且 ≥ 30 天未跟进 | 红 |
| 订单/回款 | 单笔取消订单 ≥ 50 万元，或应收逾期 ≥ 30 天 | 红 |

- 风险编号：`R-YYYYMMDD-NNN`。
- 24 小时内同对象、同规则再次触发时合并，追加证据，不重复建单。
- 状态：待认领、处理中、已关闭、误报、长期跟踪。

### SLA

| 级别 | 认领时限 | 关闭时限 |
|---|---|---|
| 红色 | 4 小时 | 3 个工作日 |
| 橙色 | 8 小时 | 5 个工作日 |
| 黄色 | 1 个工作日 | 10 个工作日 |

超时后自动升级，最多升 2 级；批处理会检查，打开风险详情时也会做惰性检查。

## 八、自测

```bat
.venv\Scripts\python scripts\selftest.py
```

该脚本会启动独立临时服务、使用临时数据库，不影响 `data/mvp.db`，覆盖登录、权限、脱敏、日报/周报、指标、质量、规则、风险闭环、导出、幂等、审计、OpenAPI、超时惰性升级、发布时间、周报范围、证据计数、四舍五入和缺源文件回滚等 32 个场景。

页面自测需要先启动服务，然后运行：

```bat
.venv\Scripts\python scripts\browser_selftest.py --base http://127.0.0.1:8000
```

脚本用 Edge headless 截图到 `data/screens/`，检查 1280/1440/1600px 横向溢出、控制台 JS 错误，并回归 1280×720、1280×800、1440×900、1600×900 首屏，确认 3 条结论、6 张指标卡和风险 Top3 完整可见。注意：它会在当前数据库中执行一次认领和关闭，建议对临时库运行。

自测结果见 `docs/开发自测报告.md`。**自测不是验收结论。**

## 十、已知限制

- 演示登录没有密码，不能当作生产认证；Cookie 未启用 `Secure`，因为本地是 HTTP。
- 单机单进程 SQLite，适合演示和小规模试用，不适合高并发生产。
- 演示业务日期固定为 2026-10-24；真实接入后应改为当天日期和真实数据源。
- 没有内置定时调度；真实使用时可用 Windows 任务计划程序定时调用 `scripts/run_daily.py`。
- 没有邮件、短信、企业微信通知，只有站内通知。
- 没有生产部署、HTTPS、反向代理、备份恢复方案。
- 只支持 PC Web 1280–1600px；不做手机端。
- 演示规则参数已能调整，但规则逻辑仍是 MVP 版本，未做复杂行业配置。
