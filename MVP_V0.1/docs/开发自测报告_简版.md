## 一、您现在能怎么用

双击 `start.bat`，等窗口出现访问地址后，用浏览器打开：

**http://127.0.0.1:8000**

登录页点任意一个演示账号即可，不用密码。建议按这个顺序体验：

1. 看“今日简报”；
2. 进“风险中心”，点开一条风险看证据；
3. 认领，再关闭；
4. 看“周报复盘”；
5. 到“导出中心”导出 Excel 或打印日报。

## 三、需要您拍板的 4 件事

1. **演示登录能否接受？**
   现在点账号就进，没有密码，只适合本地演示。正式上线前必须换成公司统一登录。请确认 MVP 阶段是否接受这种演示方式。

2. **真实数据由谁提供？**
   现在系统读取 10 个 CSV 文件。需要确认：能否从 CRM/ERP 导出同样字段？如果字段不一样，是由 IT 提供接口，还是先做人工导出？

3. **营销 ROI 的口径能否接受？**
   “ROI”是“投入一元营销费用带来多少签约额”。现在投放费用只有公司总数，所以 ROI 只能算到公司层，不能分部门。是否接受？如果必须分部门，需要补部门级投放费用数据。

4. **两类风险的金额是否要改？**
   “线索异常”和“商机覆盖”的涉及金额现在显示 0，这是按期望清单来的。是否要改成“可能影响的金额”估算？如果不改，演示时需要向观看者解释一句。

## 四、还没做或有限制

- **不做手机端**：按您的要求，没有手机页面、手机预览和移动端适配；只保证电脑 1280–1600 像素宽。
- **适合演示，不适合多人同时用**：本地 SQLite 数据库，单机单进程；正式使用要换生产数据库。
- **没有自动定时跑**：现在需要手动运行或由 Windows 计划任务调用；也还没有邮件、短信通知。
- **日期是固定的**：演示业务日期固定为 2026-10-24；接真实数据后要改成当天。
- **没有独立单元测试**：主要靠 31 个端到端场景和 Edge 浏览器实测；独立测试与验收还需要另外安排。
