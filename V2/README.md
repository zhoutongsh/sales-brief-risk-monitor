## 二、怎么把系统跑起来

1. 把整个 `03-可运行系统` 文件夹复制到电脑上，双击 `启动销售监控系统.exe`。
2. 第一次启动会自动建库、生成 30 天演示数据、跑一次批处理，并打开浏览器，通常 5–15 秒。
3. 浏览器地址：<http://127.0.0.1:8000>；接口文档：<http://127.0.0.1:8000/docs>。
4. 四个演示账号：`u_gm`（总经理）、`u_sd`（销售总监）、`u_bu`（事业部总经理）、`u_sm`（部门销售经理）。
5. 关掉黑色窗口即停止服务；数据保留在 `03-可运行系统/data`，下次启动还在。

如果 Windows 提示“已保护你的电脑”，点“更多信息” → “仍要运行”。更细的启动、重置数据和排错，见 `03-可运行系统/使用说明.md`。

## 三、这个包里没有什么

`03-可运行系统` 里是打包好的 exe，**不需要安装 Python**。为了仓库干净、避免泄露本机环境和运行数据，以下内容**没有上传**：

- `.venv` 本地运行环境。
- `data/mvp.db` 演示数据库（首次启动会自动生成）。
- `.pytest_cache`、`__pycache__` 等缓存。
- `*.log`、`*.out`、`*.err` 运行日志。

源代码和测试代码在仓库根目录的 `MVP_V0.1` 文件夹，供技术人员查看。

## 四、必须说清的边界

- 登录是“选择演示账号”，没有密码、短信或单点登录；不能放公网，不能录入真实客户信息。
- 数据来自 10 个 CSV，未接真实 CRM/ERP；只有站内通知，未接钉钉、企微、邮件。
- 批处理目前人工触发，没有内置定时器；“08:30 发布”是计划时间。
- 风险规则为 6 类、8 个独立触发条件，不是“12 条规则已完成”。
- 只做电脑网页，未做手机端；未做 50 并发压测和 12 个月留存验证。
- 1000 条线索数据与现有演示库同源；如果本意是换新数据，需要替换后重跑。
